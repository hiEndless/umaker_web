# UMAKER Signal Design

UMAKER is an AI-native quantitative intelligence system, not a generic AI SaaS site and not a crypto trading bot brand.

The visual direction is:

```text
Ice White + Deep Graphite + Intelligence Blue + Cyan Data Flow + Sparse Emerald Signal
```

UMAKER is not a green brand. It is a cold, blue-toned quantitative intelligence system where emerald appears as a scarce system signal.

## Core Rules

1. Data before decoration.
2. Signal is scarce.
3. Structure creates hierarchy.
4. Particle means relationship.
5. Pixel means data.
6. Animation must represent system state.
7. AI is infrastructure, not the visual subject.
8. Live means real.
9. Intelligence blue, UMAKER emerald, and financial positive green are separate meanings.
10. Public performance must carry provenance.

Use black, deep graphite, ice white, cold blue, cyan, silver gray, hairlines, spacing, and typography as the primary visual system. Use emerald only for UMAKER identity signals, active states, selected states, focused nodes, CTA confirmation, live/validated state, and critical accents.

## Avoid

- Green-dominant pages
- Replacing the whole Jarvis-style blue atmosphere with emerald
- Purple AI gradients
- Neon overload
- Cyberpunk city visuals
- Glassmorphism everywhere
- Crypto coin graphics
- Robot or AI brain graphics
- Decorative particle backgrounds without semantic relationships
- Dense dashboards on public homepage sections
- Fake live metrics or unproven performance claims
