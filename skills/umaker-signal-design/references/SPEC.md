# UMAKER Core Visual Specification

## Identity

UMAKER should feel like a real quantitative research and market intelligence infrastructure that is quietly running in the background.

The core visual language:

```text
Ice White
+ Deep Graphite
+ Intelligence Blue
+ Cyan Data Flow
+ Silver Hairline
+ Sparse Emerald Signal
+ Particle Data Topology
+ Pixel Data Visualization
+ Quantitative Research Interface
```

## Color Governance

Cold blue is the primary technology atmosphere. Cyan expresses data flow, computational depth, and particle movement. Emerald is a scarce UMAKER signal accent, not the page atmosphere.

Use blue/cyan for:

- Hero particle fields
- Data flow lines
- Agentic system space
- Computational glow
- Section transition atmosphere

Use emerald for:

- Active node
- Selected state
- Signal pulse
- CTA edge
- Focused data point
- Live indicator

Do not use emerald for:

- Large backgrounds
- Whole page washes
- Every icon
- Every positive-looking number
- Decorative glow fields

Financial positive green is separate from UMAKER emerald. Do not use emerald as a shorthand for profit.

## Typography

Use:

```text
UI / Latin      Inter
Chinese         Noto Sans SC
Data            JetBrains Mono
```

Wordmarks and headings should feel technical and precise. Avoid playful rounded fonts, crypto display type, and retro terminal fonts.

## Density

Homepage: low density, more negative space.

Engine: medium density, structured explanation.

Monitor: high density, terminal-like table and metrics.

Client dashboard: very high density, operational interface.

## Motion

Motion must explain a system state:

- Data clustering into market structure
- Factor node activation
- Signal propagation
- Section transition on scroll
- Freshness or running state

Avoid animation that only makes the page look futuristic.
