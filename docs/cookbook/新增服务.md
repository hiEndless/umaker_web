# 新增服务

从 `apps/api`（后端）或 `apps/web`（前端占位）复制后改名。不要在根目录写业务。

## 后端

1. 复制目录为 `apps/<name>/`，改 `package.json` 的 `name` 为 `@umaker/<name>`。
2. 改 `wrangler.toml` 的 `name`、KV/D1 等绑定；复制 `.dev.vars.example`。
3. 保留 `src/api|application|domain|infrastructure`、`src/main.ts`、`src/worker.ts`。
4. Node `tsconfig.json` 排除 `worker.ts` 与 `infrastructure/cloudflare/**`；Workers tsconfig 排除 `main.ts`。
5. 绑定只通过 `@umaker/cloudflare-adapters`；领域层不引用运行时 API。
6. 补 `docs/契约说明.md`、`docs/迁移说明.md`。
7. 若有新契约：走根 `AGENTS.md` 四件套，并 `pnpm generate:contracts`。
8. 把回放入口从 `@umaker/api` 改到新服务（`verification/replay/run_replay.ts`、服务内 `test/replay-once.ts`）。
9. 根 `package.json` 的 `typecheck:workers` 加上新服务 filter。
10. 需要 Docker 时补 `docker/` 与 compose 服务。
11. 写一条 `.agents/notes`。跑 `pnpm verify:quick`；涉及运行时再跑 `pnpm verify:all`。

## 前端占位

1. 复制 `apps/web` 为 `apps/<name>/`。
2. 改 `package.json`、`wrangler.toml` 项目名。
3. 替换 `public/`；不要套后端 DDD 目录。
4. 布局守卫通过 `package.json` 的 `@umaker/web` 名称或 `wrangler.toml` 的 `pages_build_output_dir` 识别前端应用；前端应用只要求保留 `public/` 目录，不强制存在 `public/index.html`。
