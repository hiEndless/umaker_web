# 验证运行手册

## 怎么选

- 改布局、契约、文档、lint：`pnpm verify:quick`
- 改运行时、回放、Workers 类型：`pnpm verify:all`
- Agent 不要默认跑全量；CI 必跑 `verify_all`

## 本地快速

```bash
tools/local/verify_quick.sh
```

## CI 全量

```bash
tools/ci/verify_all.sh
```

## 守卫覆盖

- `check_structure_guard.ts`：目录与关键文件
- `check_app_layout_guard.ts`：apps 布局
- `check_ddd_import_boundary_guard.ts`：DDD 依赖方向
- `check_contract_change_bundle_guard.ts`：契约四件套
- `check_release_templates_guard.ts`：发布模板
- `check_compatibility_window_guard.ts`：兼容窗口
- `validate_contracts.ts`：schema/mapping/manifest/生成物
- `validate_fixture_schemas.ts`：fixture 校验
- `validate_contract_index_consistency.ts`：契约索引对齐
- `pnpm lint`：ESLint + TypeScript 规则
- `pnpm -r run typecheck`：Node 类型检查
- `typecheck:workers`：Workers 类型检查
