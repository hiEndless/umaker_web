# UMAKER Design Samples

参考图片已移除。

原因：

- 样图中的局部 CTA、数据、布局和文案可能被误认为正式规范。
- 官网实现应优先遵守项目内的文字规范和组件约束。
- 后续如果需要视觉参考，应基于当前规范重新生成，并明确标注 `CONCEPT`、`DEMO`、数据来源和不采纳项。

当前设计依据：

- `docs/design/brand_design.md`
- `docs/design/website_design.md`
- `docs/design/umaker_design_system.md`
- `docs/design/umaker_design_skill_adaptation_plan.md`

后续实现原则：

1. 首页优先低密度、黑色画布、稀疏语义粒子和滚动叙事。
2. Engine 使用中低密度解释市场数据、结构、状态、因子和信号。
3. Monitor 保持 table-first，但必须显示 mode、source、period、updatedAt 和 freshness。
4. 所有性能、收益、Sharpe、回撤和 LIVE 状态必须来自真实数据源；演示数据必须明确标注。
5. 不采纳开放 SaaS 暗示，包括 `注册`、`Start Free Trial`、`Create Bot`、`Connect Exchange`。
