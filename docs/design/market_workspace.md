# 市场观察工作台

路由为 `/market`，归属 `apps/web/components/market`。沿用官网的深色背景、蓝色交互强调、等宽金融数字和细分隔线；采用紧凑数据布局。交易对仅显示名称，不使用币种Logo；榜单行省略 `/ USDT`，成交额数值省略USDT单位，详情价格保留报价单位。

当前通过同源 `/api/market/` 读取UMaker真实榜单，不执行交易。页面按各榜显示快照与有效状态；不加入公开sitemap，页面noindex。官网首页布局保持原状，访问 `/market` 进入工作台。

## 分区与交互

顶部品牌导航、页面标题和行情快照；范围摘要；收益/动量切换、周期选择、搜索与重置；涨跌双榜；交易对详情和多周期归属矩阵；数据口径说明。

收益榜支持5m/15m/1h/4h/24h/5d；动量仅5m/15m，单位为百分点pp，表示相邻两段收益率之差。动量直接消费UMaker动量API，不从六个不同收益窗口相减。切换到动量时不支持的周期收敛至15m。榜单每侧最多10个交易对，保持上游方向与排名，不按收益正负重新过滤，搜索保留原榜单排名，不重新编号。

点击交易对更新详情；点击详情矩阵周期/榜单回到对应收益榜。榜单类型、周期和选中交易对保留在URL的view/window/symbol参数，刷新或直达可恢复；搜索为当前页临时状态，重置清除全部视图选择。未命中搜索显示空态和清除按钮。每30秒检查新快照，提示用户应用，保持阅读顺序；已过期条目自动隐藏，不展示无效交易/K线按钮。

矩阵使用与榜单一致的API快照，不重算排名，最多声明前10归属。右侧观察依据明确尚未接入观察池、形态和历史快照。当前归属不用于解释历史信号。手机端按涨榜、跌榜、详情纵向排列，点击交易对后滚动到详情，桌面宽屏双榜并列。

## 数据边界与后续

旧样例只保留为设计fixture，运行时不导入。服务器适配UMaker权威API；凭据不能下发浏览器。具体契约与部署要求见 `apps/web/docs/契约说明.md` 和 `迁移说明.md`。不在前端重算生产筛选/交易规则。真实接口的积累中、过期、缺失与错误必须区分，不能填0或继续显示为有效实时榜单。历史榜单与信号快照、K线标记为下一步独立范围。

验证以web typecheck、定向eslint、verify:quick及桌面/手机浏览器交互检查为准。真实上游联调与本地页面检查单列证据；线上Workers部署需另外验收。
