# UMAKER Brand Design

## 品牌核心

UMAKER 不是一个普通 AI Trading 产品，也不是开放式交易机器人网站。

品牌核心是：

```text
Market Intelligence Core
```

对外一句话：

```text
Markets generate complexity. UMAKER turns that complexity into structure, factors, and actionable intelligence for systematic strategies.
```

中文表达：

```text
市场产生复杂性，UMAKER 将这种复杂性转化为结构、因子和可被系统化策略消费的量化智能。
```

## 品牌定位

主定位：

```text
The Intelligence Layer for Quantitative Trading
```

辅助定位：

```text
Real-Time Market Intelligence for Systematic Trading
```

```text
AI-Native Quantitative Intelligence
```

推荐优先使用第一句。`AI-Native` 可以作为能力描述，不应成为全部品牌主体。

## 品牌关键词

核心关键词：

- Quiet

- Technical
- Systematic
- Data-driven

- Real-time

- Minimal

视觉来源：

```text
Quant Terminal

Scroll Narrative
```

## 品牌人格

UMAKER 应该像：

```text
一套正在运行的量化研究基础设施
```

而不是：

```text
一个努力显得未来感很强的 AI 初创公司
```

用户打开 UMAKER 后应形成的感受：

1. 这是专业的数据系统。
2. 它正在实时运行。
3. 它不是 AI Chatbot，而是在做量化研究。
4. 策略和监控似乎有真实运行依据。
5. 用户愿意进一步查看策略和表现来源。

## 核心叙事

主链路：

```text
Market
  -> Structure
  -> Factor
  -> Signal
  -> Strategy
  -> Validation
  -> Performance
```

简化视觉表达：

```text
DATA -> STRUCTURE -> FACTOR -> STRATEGY -> PERFORMANCE
```

UMAKER 官网只负责建立统一世界观；产品页面解释具体能力；Monitor 证明运行状态；Client Dashboard 服务私有客户操作。

## 产品边界

公开品牌必须保留模块独立性：

- UMAKER 是实时市场智能与因子生产中枢。
- Strategy Factory 是可组合、可验证的策略生产基础设施。
- Strategy 是独立量化策略产品。
- Monitor 是公开策略运行和表现展示层。
- Client Dashboard 是私有托管交易操作界面。
- Agent 是贯穿研究、验证、监控和执行的工作流机制。

不要把这些模块伪装成一个已经完全耦合的一体化 SaaS。

## 视觉语言

推荐方向：

```text
Quiet Signal
  + Quant Terminal
  + Deep Black Canvas
  + Emerald Signal
  + Particle Data Topology
  + Pixel Data Visualization
  + Progressive Scroll Narrative
```

设计目标不是炫技，而是可信、精确、可阅读、可扩展。

官网首页应比终端和监控台更有呼吸感。首屏优先建立品牌判断和核心隐喻，不要把用户直接压入高密度交易终端。高密度数据应放在 Monitor、Strategy Detail 和 Client Dashboard，Homepage 用滚动叙事逐步解释系统。

## 色彩

基础色：

```text
Page Background       #050706
Hero Canvas           #000000
Canvas Soft Black     #030403
Surface               #0A0F0D
Surface Elevated      #0D1110
Border                #18211E
Border Strong         #26332E
Primary Text          #F1F5F3
Secondary Text        #8B9691
Tertiary Text         #5F6B66
Disabled Text         #3B4440
```

纯黑可以用于 Hero particle canvas、全屏滚动转场和局部沉浸式拓扑画布，但不建议整站全部使用 `#000000`。纯黑会强化粒子对比，也会放大阅读压力和 neon 风险。默认页面背景应使用接近黑色的深灰绿黑，例如 `#050706` 或 `#030403`，让界面保留一点空气感。

品牌信号：

```text
Brand               #0D9488
Brand Bright        #34D399
```

语义色：

```text
Positive            #22C55E
Negative            #EF4444
Warning             #F59E0B
Neutral             #6B7280
```

重要规则：

```text
Brand Green != Financial Positive Green
```

品牌绿色代表 UMAKER system signal、focus、active、selected、live。金融正向绿色代表收益、价格上涨、positive return。Factor 强度不一定等于赚钱，不得简单全部染成 positive green。

## 字体

推荐字体：

```text
UI       Inter
Chinese  Noto Sans SC
Data     JetBrains Mono
```

数据、时间、交易对、因子 ID、策略 ID 和指标值优先使用 Mono：

```text
BTCUSDT
F-023
STR-023
03:21:42 UTC
+32.84%
2.31
8.21%
```

Label 可使用 uppercase 和轻微 letter spacing；正文不要全部 uppercase。

## Logo 方向

Logo 应该：

- Simple
- Geometric
- Technical
- Readable
- Scalable

不要塞入：

- AI brain
- Robot
- Crypto coin
- Candlestick
- Magic sparkle
- 复杂行情图

Logo 可以暗示 signal、node、structure 或 intelligence layer，但不能牺牲可读性。

## Particle

Particle 是品牌识别资产，但必须代表关系。

可表达：

- Market Data
- Market Structure
- Factor Similarity
- Signal Flow
- Strategy Dependency
- Agent Workflow

不可作为随机科技背景。

Brand Particle 可以使用抽象数据。Data Particle 必须声明数据来源、更新时间和 stale/unavailable 状态。

粒子应保持稀疏。首页首屏只表达一个主隐喻，例如：

```text
scattered data -> structure -> factor
```

不要在首屏同时展示数据源、策略、Agent、Monitor、收益和大量指标。滚动过程中再逐步让节点聚合、连接、产生因子、连接策略。

## Pixel

Pixel 只用于数据可视化，例如：

```text
FACTOR STRENGTH
F-023   ████████░░  0.82
F-047   ██████░░░░  0.64
```

或：

```text
MARKET DENSITY
░░▒▒▓▓████
░▒▒▓▓█████
░░▒▓▓█████
```

Pixel 不用于字体、按钮、导航、卡片、边框或整站风格。

## Motion

动画必须回答：

```text
为什么这个东西要动？
```

合理动画：

- New Factor
- New Signal
- Market State Change
- Strategy Activated
- Agent Running
- Data Streaming

不合理动画：

- Random floating cards
- Button glow everywhere
- Fast particle storm
- Endless gradient motion
- Text floating without meaning

官网动效的推荐方向是 scroll narrative，而不是单纯背景循环：

```text
Scroll 01: scattered market data
Scroll 02: data nodes form market structure
Scroll 03: structure reveals factor nodes
Scroll 04: factor emits signal
Scroll 05: signal connects to strategy
Scroll 06: monitor verifies performance with labeled data
```

动画必须能暂停、降级或替换为静态表达。移动端优先使用静态拓扑或低密度 Canvas。

## 文案风格

文案应该：

- 精确
- 克制
- 工程化
- 研究导向
- 强调结构、因子、验证和运行状态

推荐表达：

```text
Market intelligence for systematic strategies.
```

```text
Structure fragmented market data into real-time quantitative signals.
```

```text
Track strategy performance with explicit data provenance.
```

```text
Agent-driven workflows inside a constrained, auditable strategy system.
```

避免表达：

```text
AI helps you make money.
```

```text
One-click trading bot.
```

```text
Guaranteed profit.
```

```text
Risk-free income.
```

```text
AI predicts the market.
```

```text
Deploy your bot in seconds.
```

## 禁止视觉

禁止：

- Purple AI gradient
- Rainbow gradient
- Huge neon glow
- Cyberpunk city
- Floating 3D coins
- AI brain
- Robot
- Excessive glassmorphism
- Gaming UI
- Large rounded card dashboard
- Decorative particle background without meaning
- Crypto bro visual language

## 品牌 CTA

推荐：

- Explore Strategies
- View Live Performance
- Request Access
- Contact UMAKER

避免：

- Start Free Trial
- Create Account
- Create Bot
- Start Trading
- Connect Exchange
- Deploy Bot

当前商业表达：

```text
Private Quant Access
UMAKER currently operates through managed infrastructure and private client access.
```

## 数据与可信度规则

品牌不能靠虚构指标建立可信度。

任何公开指标必须标注：

- mode: LIVE / PAPER / BACKTEST / SIMULATED / DEMO / RESEARCH
- period
- source
- updatedAt
- freshness: FRESH / STALE / DEGRADED / UNAVAILABLE / ERROR

不得混淆实盘、模拟、回测和研究数据。

## 最终品牌判断

UMAKER 最值得建立的不是一个漂亮网站，而是一套视觉语言，让用户自然理解：

```text
市场
  -> 结构
  -> 因子
  -> 策略
  -> 验证
  -> 运行
```

这套语言建立后，新 Factor、新 Strategy、新 Research、新 Agent、新 Market Model 和新 Dashboard 都可以进入同一个 UMAKER 世界，而不需要重新定义品牌。
