- `Tier` 与 `contracts/versions/manifest.json` 对齐：`example` 表示模板演示契约；新增生产契约时使用 `production`
- TS 消费侧生成物位于 `packages/contracts-ts`（生成后提交）

## 契约变更流程

1. 更新 `contracts/schemas` 与 `contracts/mappings`
2. 更新 `contracts/versions/manifest.json`
3. 更新服务内 `docs/契约说明.md` 与 `docs/迁移说明.md`
4. 执行 `pnpm generate:contracts` 并提交生成物
5. 扩充 `verification` 与 `tools` 守卫入口

## 契约四件套守卫

`verification/guards/check_contract_change_bundle_guard.ts` 检查 manifest、契约索引、服务文档、fixture、verification 与 `packages/contracts-ts` 是否成套。
