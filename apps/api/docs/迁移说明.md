# api 迁移策略

当前契约版本：1.0.0

兼容窗口策略：
- 新字段先以 optional 进入 schema
- 至少一个迁移窗口后再评估升级为 required
- breaking 变更必须同步升级 `contracts/versions/manifest.json` 并更新 `docs/contracts/契约索引.md`
- 变更后执行 `pnpm generate:contracts` 并提交 `packages/contracts-ts`

当前兼容路径：
- 无额外兼容壳；调用方直接走 `src/api/handlers.ts`
- 若后续引入兼容导出，需在此标注下线条件
