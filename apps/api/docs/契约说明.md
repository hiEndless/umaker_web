# api 契约说明

服务消费与产出的跨服务结构以 `contracts/schemas/umaker_web_event.schema.json` 为准。
TS 侧通过 `@umaker/contracts-ts` 的生成类型与 zod schema 消费。

字段语义：
- `event_id`: 事件唯一标识
- `status`: 处理状态，枚举 accepted/rejected
- `reason_code`: 原因码，枚举 none/invalid_input/system_error
- `payload`: 扩展上下文对象，可选

分层落点：
- 接口层：`src/api/handlers.ts`
- 应用层：`src/application/use_cases/process_event.ts`
- 领域层：`src/domain/models.ts`、`src/domain/policies.ts`
- 基础设施层：`src/infrastructure/repositories/`
