# 市场工作台真实API接入

market_workspace.schema.json 1.0.0为新增契约，market-v1兼容窗口，无既有生产下游或数据库迁移。固定样例保留作设计fixture，运行时不再导入。

本地 `.env.local`：UMAKER_API_BASE_URL=http://127.0.0.1:8092、UMAKER_API_TOKEN为UMaker现有读取令牌。线上BASE_URL=https://api.umaker.org已登记wrangler.toml，令牌通过Workers secret配置，不能用NEXT_PUBLIC_或提交真实env。Next本地修改env后需确认开发服务器已加载；Workers部署需要同版web/生成物及私有secret。Workers当前nodejs_compat及compatibility_date使用进程环境；发布前须在preview实测配置和鉴权，不能以本地Node联调替代。

若本机没有API实例，可使用受信SSH端口转发连接既有UMaker API，不重启远端或复制数据库。此次本机私有文件复用既有持久token，没有更改生产认证。

回滚到旧前端仅为设计回退，不将固定样例标为实时。缺配置显示数据源未配置，禁止自动访问示例域名或匿名兜底。新字段在一个兼容窗口内先optional，删除/改语义必须升版。移除真实接入需同时撤销前端轮询和服务器适配入口。

本地SSH转发为当前开发会话提供真实上游，退出该转发后需启动本机UMaker API或恢复受信转发。线上Workers没有复用本地转发；上线需确认api.umaker.org的TLS/连通性与Workers私有secret。此次不自动修改线上Worker或发布站点。

## market-v1 可选报价扩展

新增optional quotes，1.0.0既有字段语义不变；至少本兼容窗口内保持optional。先部署UMaker的exchange_ingestion_service与api_service，确认GET /api/v1/market/quotes有有效报价，再发布前端。旧后端404或报价缺失不影响榜单，只显示未提供/旧快照；不增加交易所调用。quotes-v1生产契约与窗口见UMaker的候选池行情报价契约与迁移.md。回滚前端及生成物即可恢复旧展示；回滚后端报价键自然过期，其他榜单不变。严格旧版BFF消费者如有独立部署需先升级optional字段解析器；浏览器与BFF同版发布。

兼容旧标签页：`GET /api/market/`默认维持旧字段集合；新页面请求`?include_quotes=1`才包含optional quotes。旧BFF忽略该查询参数时新页面仍接受无quotes响应。至少market-v1窗口内保持此opt-in兼容；移除需升版与迁移。
