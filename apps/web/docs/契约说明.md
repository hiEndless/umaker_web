# 市场工作台接口契约

`market_workspace.schema.json` / `market_workspace.mapping.json` 1.0.0，兼容窗口market-v1。`GET /api/market/` 返回16个独立榜单：收益6周期×2方向，动量5m/15m×2方向，每榜最多10条，沿用上游原rank，不按正负重新过滤收益榜。scope=candidate_pool；pool_size为24h榜单候选并集大小，不是全交易所币种总量。

每榜包含as_of/available/expires、有效/不足数量、ready/partial/not_ready/unavailable/stale状态。分周期分别来自上游快照，不承诺跨窗口同一批次。value是小数比例的十进制字符串，收益显示百分数、动量显示百分点，均乘100一次。24h return_24h也是比例；不能混用百分数。

未知/过期不填0、不保留可用entries；积累中HTTP200空榜且not_ready。全不可用HTTP503，部分成功200；两者响应均为完整受验证契约。错误原因只输出白名单，不泄露token/主机/上游错误正文。当前UMaker榜单接口没有价格/成交额，页面明确显示“—”，没有样例兜底。

API适配层仅做HTTP配置；应用层readMarket限制4路并发；基础设施HttpMarketReader访问固定白名单上游路由及严格输入校验；领域模型不依赖网络或运行时。服务端凭据只从私有环境加载，使用redirect:manual并拒绝所有非2xx（包括重定向），拒绝外部明文HTTP及过大响应。响应no-store，进程内单槽10秒缓存/请求合并，未过期方可命中；单次上游2.5秒、聚合8秒取消。无新服务/数据库/依赖。

前端定时检查30秒，提示新快照后由用户应用，避免阅读中重排；到期自动隐藏当前行。多周期矩阵只声明前10排名，未查到不等于交易对无收益；异常窗口显示数据未就绪。价格、观察池和形态没有伪造值。
