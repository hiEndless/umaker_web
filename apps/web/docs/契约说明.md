# 市场工作台接口契约

`market_workspace.schema.json` / `market_workspace.mapping.json` 1.0.0，兼容窗口market-v1。`GET /api/market/` 返回16个独立榜单：收益6周期×2方向，动量5m/15m×2方向，每榜最多10条，沿用上游原rank，不按正负重新过滤收益榜。scope=candidate_pool；pool_size为24h榜单候选并集大小，不是全交易所币种总量。

每榜包含as_of/available/expires、有效/不足数量、ready/partial/not_ready/unavailable/stale状态。分周期分别来自上游快照，不承诺跨窗口同一批次。value是小数比例的十进制字符串，收益显示百分数、动量显示百分点，均乘100一次。24h return_24h也是比例；不能混用百分数。

未知/过期不填0、不保留可用entries；积累中HTTP200空榜且not_ready。全不可用HTTP503，部分成功200；两者响应均为完整受验证契约。错误原因只输出白名单，不泄露token/主机/上游错误正文。价格和成交额由独立quotes接口提供；缺失时显示“—”，没有样例兜底。

API适配层仅做HTTP配置；应用层readMarket限制4路并发；基础设施HttpMarketReader访问固定白名单上游路由及严格输入校验；领域模型不依赖网络或运行时。服务端凭据只从私有环境加载，使用redirect:manual并拒绝所有非2xx（包括重定向），拒绝外部明文HTTP及过大响应。响应no-store，进程内单槽最长10秒缓存/请求合并，距离最早过期不足10秒时不命中缓存，含失败榜时缓存最多5秒；单次上游3.5秒、聚合15秒取消，浏览器18秒超时。无新服务/数据库/依赖。

前端仅在页面可见时按最长30秒的计划间隔自动获取并应用新快照；按各榜最早过期时间提前10秒刷新，最小间隔5秒，失败或过期后5秒重试，恢复可见或重新获得焦点时立即刷新；后台暂停定时请求；当前周期、搜索和选中交易对保持不变；到期保留上次成功快照、原排名和原时间，榜单及矩阵明确标注旧快照；新有效快照自动替换，合法空榜仍清空旧排名。多周期矩阵只声明前10排名，未查到不等于交易对无收益；异常窗口显示数据未就绪。价格、观察池和形态没有伪造值。

可选quotes：每币最新成交价last_price、滚动24小时USDT成交额quote_volume_24h及原生price_at_ms、发布available_at_ms和expires_at_ms；来自GET /api/v1/market/quotes（market_quotes.schema.json 1.0.0），最多200条。价格/成交额不乘100，成交额不是币数量。对同源候选报价单独校验，失败不抹除排名；过期保留原价并标旧快照，缺失显示—。数据作用域为币安USDT永续，旧后端缺路由时optional字段省略。聚合新增一次后端只读请求，行情采集不增加HTTP请求。

兼容旧标签页：`GET /api/market/`默认维持旧字段集合；新页面请求`?include_quotes=1`才包含optional quotes。旧BFF忽略该查询参数时新页面仍接受无quotes响应。至少market-v1窗口内保持此opt-in兼容；移除需升版与迁移。

聚合读取使用同一4路队列，候选池和报价优先入队，不再等全部榜单结束后串行读取报价；同一候选池请求仍合并。HTTP预算3.5秒覆盖后端3秒执行预算；4路请求队列的4轮读取预留15秒总预算，浏览器18秒超时。部分窗口失败仅在对应当前视图显示更新失败，其他窗口继续自动重试，不影响已成功报价和榜单。

报价在获取时通过有效性校验后，若等待其他窗口期间过期，聚合响应仍保留原值与原expires_at_ms，由页面标为旧快照；不续期、不声称实时，防止首次读取因传输耗时再次变成缺失。
